Windows security note
The current installer is an unsigned CMD file. Your browser or Windows may show a warning. Verify that the file came from this GitHub repository and run it only if you trust it.

Frequently asked questions

How do I close the pet?

Right-click the pet or the paw icon in the system tray, then select Exit.

How do I uninstall it?

Turn off Start with Windows in Settings, exit the app, and delete the install folder and desktop shortcut. Back up the user_pets folder first if you want to keep custom pets.

What if face detection fails?

That is not an error. Drag over any person, animal, character, toy, or meme to select the area manually.
