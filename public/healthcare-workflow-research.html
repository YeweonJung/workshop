01 / FINDINGS

가장 명확한 출발점은 ‘퇴원연계 서류 접수·보완’입니다.

공식 매뉴얼이 문서 누락과 착오를 검토하고 병원에 보완을 요청하도록 정하고 있어, 해결하려는 업무를 구체적으로 정의할 수 있습니다. 다만 업무가 존재한다는 사실과 유료 제품이 필요하다는 판단은 별개입니다. 실제 처리량·시간·기존 자동화 수준은 아직 확인되지 않았습니다. [S01]

업무 근거

퇴원연계 접수 검수

제출서류 확인 → 보완 요청 → 지원계획 초안의 흐름이 명시됩니다.

가장 먼저 실제 한 건을 따라가 볼 후보.
관행 근거

전자·팩스 접수 병존

전북대병원은 전자 의뢰와 팩스·방문 접수를 함께 안내합니다.

전자화된 병원도 입력 채널별로 조사.
[S04]
제품 가설

파일 접수 + 근거 검수

문서 묶음과 누락·차이를 원문 위치와 함께 보여주는 기능부터 검증합니다.

촬영 기능의 필요성은 현장 비율로 결정.
권고하는 첫 제품 범위
특정 병원·지자체 협약의 퇴원연계 서식 묶음에 대해 제출 조건 확인, 문서 간 식별정보 대조, 보완 요청 초안을 제공하고 담당자가 확정하는 도구. 우선 한 업무·한 서식군에 한정하여 기존 체크리스트보다 빠르고 정확한지 검증합니다.

확인공식 지침·기관 안내에 명시된 내용　가설업무구조에서 도출한 제품 제안　미확인실측·현장 화면·인터뷰가 필요한 내용. 아래 OCR·촬영·우선도 평가는 측정된 시장성 점수가 아닙니다.

02 / WHAT CHANGED

붙여넣은 조사 내용에서 보완한 부분

기존 설명추가 확인·수정제품에 주는 의미
퇴원연계의 PDF·출력물 사용은 현장 확인 필요1월 매뉴얼은 시스템 구축 전 이메일·공문·스캔 PDF 제출을 명시. 다만 9월에도 같은 비율로 사용되는지는 미확인. [S01]문서 수신 근거는 강화됐지만, 과도기 업무에만 의존하는 사업인지 확인해야 함.
진료의뢰·회송은 전자정보 중심이라 덜 매력적전자 경로 외에 팩스·방문 접수도 공식 병원 안내에 존재. 전자 의뢰 수가 요건과 일반 접수 경로는 다름. [S04] [S15]병원 전체를 제외하지 말고 비전자 의뢰의 월 처리량을 확인.
퇴원연계 뒤 조사·종합판정 진행퇴원환자는 병원 자료를 활용해 신속히 통합지원회의로 진행하는 경로가 있음. 자료가 완비되면 지자체 자체조사를 생략할 수 있음. [S01]모든 사례에 동일한 조사서·평가표를 필수로 요구하면 오경고 발생.
재택의료센터는 여러 기록이 만나 재입력이 많을 것다직종 기록과 요양기관 정보마당 제출은 확인. 외부 문서 유입 비율과 중복 입력량은 미확인. [S06]외부자료 접수와 내부 월말 청구 취합을 다른 제품 후보로 측정.
지시 주 2회, 기록 주 1회이면 불일치비교기간, 중간 변경 지시, 입원·취소, 아직 입력되지 않은 기록을 함께 확인해야 함. 변경 협의 기록 의무는 고시에서 확인. [S07]횟수 차이는 확인 신호이며 서비스 미수행·청구 위반의 확정값이 아님.
협약 1,030개 병원과 601건이 시장 근거각각 4월 말 협약 수와 3.27–4.24 초기 연계 실적. 다른 시점·성격의 수치이며 현재 월 수요나 유료고객 수로 환산 불가. [S02]기관별 현재 월 처리량·구매권한·예산을 별도 조사.

제도상 확인된 업무와 기관별 미확인 운영을 각 답변 안에서 구분했습니다. 예시는 모두 제품 동작을 설명하기 위한 합성 사례입니다.

8개 업무 표시

퇴원연계우선 현장검증

협력병원 → 지자체 퇴원연계 접수

근거 수준: 서류 제출·검토·보완 요청 확인 [S01] [S12]

병원 담당자 작성시군구 서류 접수누락·착오 보완지원계획 초안
문서 출처
협력병원의 퇴원지원 담당자가 제출. 기본 서식은 선별평가표·통합지원신청서·개인정보 동의서·환자평가표. 협약에 따라 지자체가 평가하는 예외 경로도 있다.
문서 형태
2026년 1월 매뉴얼은 연계시스템 정식 구축 전 이메일·공문·스캔 PDF 제출을 우선 활용하도록 안내한다. 종이 원본의 스캔은 명시되지만, 사진·팩스의 전국 사용 비율은 미확인. 이 과도기 안내를 9월 현장 전체에 적용할 수는 없다.
받는 담당자
시군구 통합돌봄 전담조직. 역할 조정에 따라 보건소가 맡을 수 있다. 보내는 쪽은 의료사회복지사·간호사 등 병원 담당자.
입력·보관 시스템
접수 후 지자체 통합돌봄 업무·개인별 지원계획으로 연결. 모든 협력병원 PDF의 어느 항목이 행복이음 어느 화면에 재입력되는지는 공개 자료로 미확인. 담당자 실제 화면을 확인해야 한다.
현재 확인·수작업
공식 확인: 구비서류 내용·표준양식 검토, 누락·착오 보완 요청, 병원 자료와 자체조사 결과를 종합한 계획 초안 작성. 키보드 재입력 횟수·시간·반려 빈도는 아직 실측하지 않았다.
OCR만으로 해결?
아니오. 스캔 문자의 인식 이후 서식 분류, 환자별 묶음, 협약별 제출 조건 확인이 필요하다. 텍스트 PDF는 텍스트 추출이 먼저다.
문서 비교·누락 검사
후보 규칙: 다른 환자 자료 혼입, 신청서와 평가표의 식별정보 불일치, 동의 항목·날짜·담당자 연락처 확인. 환자평가표 부재는 예외 경로일 수 있어 곧바로 오류로 처리하면 안 된다.
촬영 기능 필요성
초기 핵심 기능으로 보기 어렵다. 이미 받은 PDF 업로드가 우선. 서명 원본을 휴대전화로만 확보하는 업무가 실제 관찰될 때 촬영 기능을 추가한다.
합성 예시: 신청서와 환자평가표의 생년월일이 다르면 원문 두 위치를 보여주고 확인을 요청한다. 평가표 자체가 없으면 “지자체 평가 경로인지 확인”으로 분기한다.

현장 확인: 9월 현재 제출 채널, 지자체별 서식 변형, 문서 한 묶음당 검토시간, 보완 사유, 구매예산.

퇴원연계연계 기능 우선 확인

요양병원 → 지자체 전자 퇴원연계

근거 수준: 전자 시스템 간 경로 확인 [S01] [S03]

환자지원팀 평가퇴원지원 표준계획요양기관 정보마당행복이음·서비스 회신
문서 출처
요양병원 환자지원팀의 퇴원지원 표준계획서 등. 일반 협력병원 서류 제출과 사업·수가 체계가 다르다.
문서 형태
매뉴얼에 요양기관 정보마당의 환자지원시스템과 지자체 행복e음 사이의 전자연계가 제시된다. 외부 의료정보 첨부물의 매체 구성은 별도 확인 대상.
받는 담당자
병원 환자지원팀 → 시군구 전담조직. 이후 지자체가 서비스 정보를 병원으로 회신하는 흐름.
입력·보관 시스템
보내는 쪽: 요양기관 정보마당 환자지원시스템. 받는 쪽: 행복e음. 원문은 2025.12.31 전국 229개 지자체 연계 완료를 명시한다. 이것이 모든 필드의 자동 채움이나 무오류 전송을 의미하지는 않는다.
현재 확인·수작업
환자 평가·계획 수립은 사람의 전문 업무. 전자연계 이후 남는 재입력·첨부물 열람·오류 정정의 구체적 범위는 미확인.
OCR만으로 해결?
구조화 전송 필드에는 불필요. 전자연계가 처리하지 못하는 스캔 첨부가 반복적으로 발생하는지부터 확인한다.
문서 비교·누락 검사
전송 실패·수신상태·버전 차이 확인은 후보지만 기존 시스템 제공 기능과 중복될 수 있다. 원본-수신값 매핑 대조의 실제 필요성을 입증해야 한다.
촬영 기능 필요성
낮음. 기존 전자 정보를 다시 출력·촬영하는 설계는 절차를 늘릴 수 있다.
합성 예시: 서비스 연계 결과가 아직 회신되지 않았을 때 “미수신”을 표시할 수 있다. 단, 기존 시스템에 같은 상태 표시가 있으면 새 기능의 가치가 줄어든다.

현장 확인: 첨부 지원 범위, 재전송·정정 기능, 공개 API, 기관 권한, 기존 화면의 검수 기능.

진료의뢰처리량 확인 후 후보

병원 진료협력센터의 외부 의뢰 접수

근거 수준: 전자·팩스·방문 접수 병존 확인 [S04] [S05] [S15]

외부 병의원 의뢰전자·팩스·방문 수신담당자 확인·전화예약·진료 준비
문서 출처
지역 병의원의 진료의뢰서와 환자가 가져오는 서류. 검사결과·진료기록 등 추가 문서의 필수 여부는 진료과·기관별로 확인해야 한다.
문서 형태
전북대병원은 진료정보교류·HIRA e-form·팩스·전화·방문·홈페이지 접수를 함께 안내한다. 전자화된 경로만 존재한다는 기존 요약은 수정해야 한다.
받는 담당자
진료협력센터 담당자. 강남세브란스는 간호사의 의뢰내용 확인 및 환자 전화예약 절차를 공개한다.
입력·보관 시스템
전자 경로: 진료의뢰·회송 중계포털과 기관 EMR/협력 홈페이지. 비전자 의뢰의 예약·등록 시스템 제품명, 전사하는 항목, 자동 연동 여부는 공개 자료로 미확인.
현재 확인·수작업
공식 확인: 의뢰내용 확인, 환자와 통화, 예약·준비사항 안내. 팩스에서 이름·연락처 등을 입력하는 실제 필드와 소요시간은 현장 검증 사항.
OCR만으로 해결?
팩스·스캔 경로에는 추출 가치가 있을 수 있다. 전자 의뢰에는 이미 필드가 있어 OCR이 필요 없다. 환자 확인·예약 조정까지 OCR로 해결되지는 않는다.
문서 비교·누락 검사
의뢰서와 첨부의 환자 일치, 문서 날짜, 요청된 검사결과 유무 등을 점검하는 후보. 진료과별 필수 첨부 기준은 병원 승인 목록으로 정의해야 한다.
촬영 기능 필요성
팩스가 파일로 저장되면 직접 파일 수신이 우선. 환자가 가져오는 종이만 있다면 스캐너 또는 촬영을 비교한다. 병원 카메라 사용률은 미확인.
합성 예시: 의뢰서 1장과 검사결과 3장을 같은 환자로 묶어 예약담당자가 검토한다. 이름만 같다는 이유로 자동 병합하지 않는다.

현장 확인: 비전자 접수 비율·월 건수, 기존 팩스함과 EMR 연동, 전화업무 비중, 접수팀 구매권한.

재택의료두 번째 현장검증

장기요양 재택의료센터 초기 접수·정보 정리

근거 수준: 다학제 기록·제출 시스템 확인 [S06] [S09]

환자·기관 의뢰기존 기록 확인포괄평가·케어플랜직종별 방문 기록
문서 출처
수급자·보호자 및 연계기관에서 의뢰받는 경로가 후보. 외부 퇴원요약·처방 자료를 실제로 얼마나 받는지와 문서 목록은 기관별 확인이 필요하다.
문서 형태
신청·동의 및 포괄평가·케어플랜 서식은 지침에 있다. 외부 문서가 종이·PDF·사진으로 유입되는 비율과 센터 내부 종이 사용률은 미확인.
받는 담당자
의사·간호사·사회복지사 팀. 외부 문서의 첫 접수자와 직종별 입력 분담은 센터별로 확인.
입력·보관 시스템
기관 자체 의무기록과 사업 기록. 장기요양 재택의료 청구 경로는 요양기관 정보마당으로 명시된다. 방문진료료는 별도의 일차의료 방문진료 사업 청구방법을 따른다. 모든 임상정보가 동일 화면에 재입력된다고 단정할 수 없다.
현재 확인·수작업
지침상 포괄평가·케어플랜과 의사·간호사 방문점검, 사회복지사 업무기록을 작성한다. 외부 문서를 읽어 정보를 옮기는 양은 미측정이며, 직접 평가하여 새로 만드는 기록과 구별해야 한다.
OCR만으로 해결?
외부 스캔 문서의 전사만 일부 지원한다. 현재 상태 평가와 치료계획 수립은 자동 추출 대상이 아니다.
문서 비교·누락 검사
후보: 퇴원 시점 기록과 초기평가 기록의 날짜·투약 목록·연락처 대조. 서로 다른 시점의 값 차이는 정상 변화일 수 있으므로 확인 사유로 표시한다.
촬영 기능 필요성
환자 집에만 종이 처방자료가 있는 경우 선택적 가치. 문서 촬영 수요와 욕창·생활환경 촬영 같은 별도 임상 용도는 구분해야 한다.
합성 예시: 퇴원 처방과 현재 복용목록이 다르면 처방일·중단일·제형을 함께 제시한다. 현재 복용량을 AI가 임의로 선택하지 않는다.

현장 확인: 기관당 신규 의뢰 수, 외부자료 의존도, 기존 EMR 연계, 직종 간 공유 방식, 실제 구매 여력.

재택의료외부문서와 분리 평가

재택의료센터 월별 기록 취합·청구 전 검수

근거 수준: 제출 서식 묶음 명시 [S06]

직종별 활동기록케어플랜과 취합청구서·명세서공단 제출·보완
문서 출처
의사·간호사·사회복지사의 기록이 행정·청구 담당자에게 모인다. 대부분 기관 내부 생성 문서이므로 외부 문서 접수라는 최초 가설과는 별도 후보이다.
문서 형태
별지 제5호 포괄평가·케어플랜, 제6–8호 직종별 기록, 제9–10호 청구서·명세서. 서식이 있다는 사실만으로 종이 작성이 많다고 볼 수 없다.
받는 담당자
기관 내 청구 담당자 또는 업무를 겸하는 실무자라는 운영 가설. 실제 담당 직종은 미확인.
입력·보관 시스템
요양기관 정보마당의 재택의료센터 시범사업 전산시스템. 장애 시 안내된 전산매체 우편 제출은 예외 경로이다.
현재 확인·수작업
여러 기록을 제출자료와 연결하는 업무가 존재. 월말 취합·이중입력 시간이 얼마나 드는지, 시스템이 이미 산정 검사를 하는지는 미확인.
OCR만으로 해결?
이미 전자 작성된 기록에는 불필요. 파일 추출·서식 매핑·날짜 기준 검사가 더 직접적인 기술 후보.
문서 비교·누락 검사
후보: 기록과 청구의 대상자·서비스일자 대응, 필수 제출자료 존재, 중복 기록. 수가 적정성 자동 판정은 적용 지침·예외까지 검증한 별도 영역.
촬영 기능 필요성
낮음. 내부 기록이 전자화되어 있다면 촬영 단계가 필요 없다.
합성 예시: 청구대상 월과 연결된 방문기록의 날짜가 다른 경우 원문을 제시한다. 누락 제출인지 날짜 오기인지 담당자가 정정한다.

현장 확인: 자동 연동 여부, 청구 반려 사유와 빈도, 월말 작업시간, 기존 청구 프로그램의 기능.

근거 수준: 지시서와 변경기록 관계 확인 [S07] [S08]

의료기관 지시서방문간호기관 수신간호 수행·변경 협의급여제공기록
문서 출처
의사·한의사·치과의사의 방문간호지시서. 장기요양 수급자·보호자가 전달하거나 기관 간 전달하는 구체 경로와 비율은 현장 확인 대상.
문서 형태
지시서와 급여제공기록의 존재는 확인. 종이 원본·스캔·전자 지시서의 사용 비율 및 사진 접수 관행은 공개 자료만으로 확인하지 못했다.
받는 담당자
방문간호기관의 간호사 등과 관리 담당자. 의사의 지시와 필요한 변경 협의 내용을 확인한다.
입력·보관 시스템
기관 기록관리 및 장기요양 급여제공기록. 재가급여전자관리시스템 전송 경로가 있으나 지시서 전체 내용이 그 시스템에 재입력되는지는 미확인.
현재 확인·수작업
공식 확인: 지시서에 따른 급여 제공, 상태 변화로 다른 처치가 필요하면 발급의사와 상의하고 급여제공기록에 기재. 확인 전화량·지시서 전사시간은 미측정.
OCR만으로 해결?
아니오. 지시서의 글자 인식 후 적용 시점·변경 지시·실제 수행기록과 연결해야 한다.
문서 비교·누락 검사
후보: 대상자·발급자·일자 확인, 상충하는 지시 버전 표시, 변경 협의 기록 존재 확인. 실제 방문 횟수 차이만으로 미수행·부당청구를 확정하면 안 된다.
촬영 기능 필요성
현장에 종이 지시서만 있다면 조건부 필요. 기관 간 파일 수신이 가능하면 촬영은 보조 수단.
합성 예시: 기존 지시와 다른 처치 기록이 있으면 변경 협의 기록을 함께 찾는다. 기록을 못 찾았을 때도 “위반” 대신 “추가 확인”으로 표시한다.

현장 확인: 지시서 수신 채널, 실제 시스템 화면, 재발급·변경 빈도, 비교 경고의 임상 검토 책임.

문서 형태

받는 담당자
기관장·사회복지사·간호 인력·행정 담당자 등 업무 분담 가설. 입소형 시설과 방문형 재가기관을 별도 표본으로 조사.
입력·보관 시스템
기관 자체 운영 소프트웨어와 공단 계약·급여 기록·청구 업무. 상용 제품명·외부 의료정보 입력란·자동 조회 범위는 미확인.
현재 확인·수작업
고시에서 계약 내용에 따른 제공 및 기록관리는 확인된다. 외부자료를 보고 자격·기간·기본정보를 대조하는 실제 작업량은 추가 확인 대상.
OCR만으로 해결?
전자조회로 확인 가능한 정보에는 OCR보다 조회·연계가 적절하다. 의료기관 스캔 자료가 남아 있을 때 제한적 추출 가치.
문서 비교·누락 검사
후보: 수급자 식별, 계약·이용기간, 자료 유효 시점, 첨부물 완결성. 처방 변경과 내부 투약기록 대조는 임상 검토를 포함하는 별도 범위.
촬영 기능 필요성
보호자 종이 제출 비율이 높을 때 선택적. 시설의 기존 스캐너와 비교해 비용·속도를 확인.
합성 예시: 계약의 이용 시작일과 외부 서류의 적용기간이 어긋나면 확인 대상으로 표시한다. 실제 급여 가능 여부는 공단 조회와 담당자 판단으로 확인한다.

현장 확인: 외부문서 월 건수, 전자조회 대체 가능성, 기존 장기요양 프로그램 기능, 기관별 예산.

받는 담당자
병원 사회복지사 등 연계 담당자와 지자체·복지기관·보건소 등 수신기관 담당자. 서비스별 창구를 확인해야 한다.
입력·보관 시스템

현재 확인·수작업
의뢰받을 기관 확인, 수신 결과·향후 계획 기록 및 회신 흐름이 있다. 전화로 수신 확인하거나 다른 기관으로 재의뢰하는 횟수는 조사 대상.
OCR만으로 해결?
아니오. 첨부 추출 외에 의뢰와 회신의 연결, 서비스 수락·거절·보완 상태를 구분해야 한다.
문서 비교·누락 검사
후보: 의뢰일·수신일·환자 식별·기관 일치, 필수 첨부 존재, 회신 대기. 수신 확인을 서비스 제공 완료로 처리하지 않는다.
촬영 기능 필요성

1. 관찰실제 흐름을 확인하고 한 서식군의 반복 검수 문제를 선택.처리량이 충분한가, 외부자료 재입력이 실제 존재하는가.
