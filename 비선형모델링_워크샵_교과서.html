1. 선형과 비선형은 무엇이 다른가

두 변수의 관계가 선형인지 비선형인지는 예측변수 x가 같은 양만큼 변할 때 반응변수 y의 변화량도 일정한가로 구분합니다.

선형 관계

ŷ = β₀ + β₁x

x가 1만큼 증가할 때 y가 항상 β₁만큼 변한다고 가정합니다. 예를 들어 BMI가 0.01 증가할 때 예측 질병 진행도가 낮은 BMI 구간에서도 높은 BMI 구간에서도 늘 3점씩 증가한다면 선형 관계입니다. β₁이 음수여도 변화량이 일정하면 선형입니다.

비선형 관계

ŷ = β₀ + f(x)

x가 같은 1만큼 증가해도 현재 x의 위치에 따라 y의 변화량이 달라집니다. 어떤 구간에서는 거의 변하지 않다가 다른 구간에서 급격히 증가하거나, 중간에서 방향이 바뀌는 U자형 관계가 나타날 수도 있습니다.

확인 질문선형비선형
x가 같은 양만큼 증가하면?y의 예상 변화량이 어느 구간에서나 같다.y의 예상 변화량이 구간에 따라 다르다.
그래프 모양하나의 직선으로 요약할 수 있다.완만함·급격함·평평함·방향 전환이 함께 나타날 수 있다.
예시BMI 0.01 증가마다 항상 예측값 3점 증가BMI가 낮을 때는 거의 변화하지 않지만 높은 구간에서는 빠르게 증가
왜 비선형이 필요한가?
임상 관계는 모든 범위에서 일정하지 않을 수 있습니다. 어느 수준까지는 변화가 거의 없다가 특정 범위에서 위험이 커지거나, 너무 낮거나 너무 높은 양쪽에서 결과가 나빠질 수 있습니다. 이런 관계를 직선 하나로만 표현하면 중요한 구간의 변화를 놓칠 수 있습니다.

3. GAM: 변수별 곡선을 더해 설명한다

GAM은 Generalized Additive Model, 한국어로 일반화 가법모형입니다. 각 예측변수의 효과를 하나의 함수로 표현하고 그 함수들을 더합니다.

예측값 = 절편 + f₁(age) + f₂(sex) + f₃(bmi) + … + f₁₀(s6)

여기서 f₃(bmi)는 BMI가 예측값을 얼마나 올리거나 내리는지를 나타내는 BMI의 전체 효과 곡선입니다. 이 변수별 효과를 분리해 볼 수 있기 때문에 GAM은 복잡한 머신러닝 모델보다 예측력이 낮을 수 있어도 관계의 방향과 모양을 해석하는 데 유용합니다.

잘하는 것

  • 각 변수의 방향과 곡선을 따로 보여준다.
  • BMI 효과를 다른 변수 효과와 분리해 설명하기 쉽다.
  • 매끄러운 전체 추세를 전달하기 좋다.

조심할 것

  • 기본 가법 구조는 변수 간 상호작용을 자동으로 포함하지 않는다.
  • 표본이 적은 양끝 구간의 곡선은 불안정할 수 있다.
  • 기저함수의 수와 평활화 정도에 따라 곡선 모양이 달라진다.
Basis expansion은 무엇인가?

복잡한 곡선 하나를 통째로 찾기보다, 미리 정한 여러 개의 단순한 함수 B₁(x), B₂(x), …를 준비하고 각각에 가중치를 곱해 더하는 방법입니다.

f(x) = θ₁B₁(x) + θ₂B₂(x) + … + θₖBₖ(x)

이렇게 여러 기저함수(basis function)의 합으로 곡선을 표현하는 것을 basis expansion이라고 합니다. B-spline은 매끄러운 비선형 관계에 널리 쓰이는 기저함수이고, sine·cosine으로 구성된 Fourier basis는 계절성처럼 주기적으로 반복되는 변화에 특히 유용합니다.

Spline은 “구간을 나눈다”는 게 무슨 뜻인가?

B-spline 기저함수 하나는 x축 전체를 똑같이 설명하기보다 특정 범위에서 주로 작동하는 작은 곡선 조각처럼 생각할 수 있습니다. BMI 관계가 거의 일정하고 단순하면 적은 수의 조각으로도 충분합니다. 완만한 구간과 급격한 구간이 섞여 관계가 복잡하면 더 많은 조각을 조합해야 그 변화를 세밀하게 표현할 수 있습니다. 조각들은 경계에서 끊어지지 않도록 매끄럽게 연결됩니다.

n_splines는 정확히 무엇을 세는가?

n_splines는 f₁(age), f₂(sex), f₃(bmi)처럼 변수별 효과 함수의 개수를 세는 값이 아닙니다. 변수 하나의 효과 함수 fⱼ(xⱼ)를 조립하는 B-spline 기저함수의 수입니다.

f₃(bmi) = θ₁B₁(bmi) + θ₂B₂(bmi) + … + θₖBₖ(bmi)

n_splines의 크기가 커지면 사용할 수 있는 기저함수가 많아져 더 복잡하고 세밀한 곡선을 표현할 수 있습니다. 학습자료에는 더 잘 맞아 적합도가 올라갈 수 있지만, 우연한 흔들림까지 따라가면 처음 보는 자료의 예측성능은 오히려 떨어지는 과적합이 생길 수 있습니다.

그림 읽는 법
여러 B-spline 기저함수의 가중합이 BMI의 효과함수 f₃(bmi) 하나를 만듭니다.

true_y <- 5 + 3*sin(x/8) +

R의 df곡선의 모습해석
4매우 매끈하고 단순큰 흐름만 잡아 과소적합할 수 있음
6조금 더 구부러짐주요 비선형 패턴 포착

R의 df와 pyGAM의 n_splines는 같은 매개변수가 아닙니다.
R bs(x, df=...)의 df는 생성되는 spline basis의 자유도와 관련되고, Python pyGAM의 n_splines는 각 smooth term에 사용하는 spline basis 개수를 지정합니다. 둘 다 곡선의 유연성과 관련되지만 숫자를 1:1로 대응시키면 안 됩니다. 각 환경에서 교차검증·보정자료 성능과 곡선 안정성을 기준으로 선택합니다.
실습 원칙
기준 결과를 저장한 뒤 숫자 하나만 바꾸고, 학습 적합도뿐 아니라 보정·평가자료의 오차와 곡선의 양끝 흔들림을 함께 비교합니다.
lam은 왜 함께 조절하는가?

lam은 곡선이 지나치게 구불거리지 않도록 누르는 평활화 벌점입니다. n_splines가 표현 가능한 복잡도의 상한을 정한다면, lam은 그 복잡성을 실제로 얼마나 사용할지 조절합니다. 따라서 n_splines를 크게 했다고 곡선이 반드시 복잡해지는 것은 아니며, 큰 lam이 굴곡을 억제할 수 있습니다. 두 값은 학습 적합도만이 아니라 교차검증이나 보정자료 성능과 곡선 안정성을 함께 보며 정합니다.

4. EBM: 가법 구조에 부스팅과 상호작용을 더한다

EBM은 Explainable Boosting Machine입니다. GAM처럼 변수별 기여를 더하지만, 얕은 나무를 반복해 학습하면서 계단형·임계형 관계와 일부 상호작용을 자동으로 찾습니다.

예측값 = 절편 + Σ fⱼ(xⱼ) + Σ fⱼₖ(xⱼ,xₖ)

Global explanation

전체 환자에서 BMI가 어느 값일 때 예측을 얼마나 올리거나 내리는지 보여줍니다. 변수 중요도와 shape function이 여기에 해당합니다.

Local explanation

특정 환자의 예측값이 왜 그렇게 나왔는지 변수별 기여를 더해 설명합니다.

RMSE와 MAE가 다르게 말할 때는?

RMSE만 크게 나빠지면 일부 환자에서 매우 큰 오차가 있었을 가능성이 있습니다. MAE가 전반적인 오차 크기라면 RMSE는 큰 실패에 더 민감합니다.

통계학 수업에서는 R²가 0~1이라는데, 왜 여기서는 음수가 나오나?

계산하는 자료와 목적이 다르기 때문입니다. 통계학 수업에서는 보통 절편이 있는 최소제곱 회귀모형을 모델을 만든 바로 그 학습자료에 다시 적용해 적합도를 설명합니다. 이때 모델은 그 학습자료의 제곱오차를 최소화하도록 만들어졌으므로 전통적인 결정계수 R²는 0과 1 사이입니다.

이 실습에서는 X_train, y_train으로 모델을 만든 뒤, 모델이 학습할 때 보지 못한 X_test를 입력해 예측값 pred를 얻고 r2_score(y_test, pred)를 계산합니다. 즉, 해당 평가자료에 직접 맞춘 회귀모형의 학습 적합도가 아니라 처음 보는 자료에서의 예측성능을 확인합니다. 이 예측이 평가자료 평균을 일괄 예측하는 기준보다 나쁘면 R²가 음수가 될 수 있습니다.

  • R² = 1: 실제값을 모두 정확하게 예측했습니다.
  • R² = 0: 평가자료의 평균만 일괄 예측한 것과 오차가 같습니다.
  • R² < 0: 평균만 일괄 예측하는 것보다 모델의 오차가 더 큽니다.
평가자료 R² = 1 − (모델의 제곱오차 합 ÷ 평균 예측의 제곱오차 합)

예를 들어 모델의 제곱오차 합이 200이고 평균 예측의 제곱오차 합이 100이면, 오차의 비율은 200 ÷ 100 = 2입니다. 따라서 R²는 1 − 2 = −1입니다. 제곱오차 각각은 음수가 아니지만, 마지막에 1에서 오차 비율을 빼므로 최종 점수는 음수가 될 수 있습니다.

한 문장으로 정리
학습자료에서 계산하는 전통적인 회귀 R²는 보통 0~1이지만, 이 실습처럼 처음 보는 평가자료에서 계산한 예측 R²는 음수가 될 수 있습니다.

참고: 여기서 “평가자료 평균 예측”은 실제 사용 시 새 환자의 결과 평균을 미리 안다는 뜻이 아니라, 모델 성능을 비교하기 위해 계산에 사용하는 수학적 기준선입니다.

# 상황 3 확장 실습 A: 원하는 Coverage에 따라 alpha 바꾸기
def make_conformal_interval(alpha):
    cal_pred = ebm.predict(X_cal)
    cal_scores = np.abs(y_cal.to_numpy() - cal_pred)

    quantile_level = min(
        1.0,
        np.ceil((len(cal_scores) + 1) * (1 - alpha)) / len(cal_scores)
    )
    q = np.quantile(cal_scores, quantile_level, method='higher')

    center = ebm.predict(X_test)
    lower = center - q
    upper = center + q
    coverage = np.mean((y_test.to_numpy() >= lower) & (y_test.to_numpy() <= upper))

    return {
        '목표 Coverage': 1 - alpha,
        'q': q,
        '실제 Coverage': coverage,
        '평균 구간 폭': np.mean(upper - lower),
    }

    make_conformal_interval(alpha=0.20),  # 목표 80%
    make_conformal_interval(alpha=0.10),  # 목표 90%
    make_conformal_interval(alpha=0.05),  # 목표 95%
])

15. “왜 그렇지?” 자주 묻는 질문

왜 평가자료를 모델 선택에 계속 사용하면 안 되나?

평가 결과를 보고 설정을 반복해서 바꾸면 평가자료의 특성까지 간접적으로 학습하게 됩니다. 그러면 평가 점수도 낙관적으로 바뀔 수 있습니다. 실제 연구에서는 개발 과정과 마지막 평가를 분리합니다.

BMI 곡선에서 특정 지점이 꺾이면 임계값인가?

바로 임계값이라고 부르지 않습니다. 표본 밀도, 모델 설정, 데이터 분할에 따라 꺾이는 위치가 달라지는지 확인해야 합니다.

Random Forest 나무들의 범위를 예측구간으로 쓰면 안 되나?

나무 간 차이는 앙상블 내부 변동이며 목표 Coverage를 갖는 예측구간과 같은 개념이 아닙니다.

Conformal Prediction이면 누구에게나 90%인가?

기본 보장은 전체 평균 Coverage에 관한 것입니다. 특정 병원, 연령대, 중증도 집단에서도 90%인지는 별도로 확인해야 합니다.

보정자료가 왜 따로 필요한가?

학습에 사용한 환자의 오차는 지나치게 작을 수 있습니다. 모델이 보지 않은 보정 환자의 오차를 써야 새 환자에서의 전형적인 오차를 추정할 수 있습니다.

한 번의 분할에서 1위면 그 모델을 쓰면 되나?

표본이 442명으로 작아 분할에 따라 순위가 바뀔 수 있습니다. 반복 교차검증과 가능하면 외부검증으로 확인합니다.

Natural Gradient Boosting. 조건부 확률분포의 모수를 부스팅으로 학습하는 방법.
CP
Conformal Prediction. 보정 오차로 목표 Coverage에 맞는 구간·집합을 만드는 방법.
RMSE
Root Mean Squared Error. 큰 오차에 더 민감한 회귀 오차.
MAE
Mean Absolute Error. 절대오차의 평균.
R²
Coefficient of Determination. 전통적인 회귀분석에서 학습자료의 적합도를 나타낼 때는 보통 0~1이다. 이 교재처럼 처음 보는 평가자료에서 예측 성능을 측정할 때는 평균 예측보다 못하면 음수가 될 수 있다.
Coverage
실제값이 예측구간 안에 들어온 비율.
Interval width
예측구간 상한과 하한의 차이.
Prediction interval
새로운 한 환자의 가능한 실제 결과 범위.
Confidence interval
추정한 평균이나 계수 같은 모수의 불확실성 범위. 예측구간과 다르다.
Conformity score
예측이 실제값과 얼마나 어긋났는지 나타내는 점수. 실습에서는 절대오차.
Quantile
값을 작은 순서로 놓았을 때 특정 비율이 아래에 위치하는 경계값.
Basis expansion
복잡한 함수 하나를 여러 단순한 기저함수의 가중합으로 표현하는 방법.
B-spline
특정 x 범위에서 주로 작동하는 매끄러운 기저함수들을 조합해 곡선을 만드는 방법.
Fourier basis
sine·cosine 함수의 합으로 주기적 변화양상을 표현하는 기저함수 체계.
n_splines
변수별 함수의 개수가 아니라, 각 변수 효과 함수 fⱼ를 조립하는 B-spline 기저함수의 수.
Shape function
특정 변수 값이 예측에 기여하는 모양을 나타내는 함수.
Interaction
한 변수의 효과가 다른 변수 값에 따라 달라지는 관계.
Overfitting
학습자료의 우연한 특징까지 외워 새 자료에서 성능이 떨어지는 현상.
Cross-validation
데이터를 여러 방식으로 나눠 모델 성능의 평균과 변동을 확인하는 절차.
External validation
다른 기관·시기·집단의 자료에서 모델을 평가하는 것.
random_state
데이터 분할과 무작위 학습 결과를 재현하기 위한 난수 기준값.
fit
학습자료에서 모델의 규칙이나 모수를 학습하는 단계.
predict
학습된 모델로 새 자료의 결과를 계산하는 단계.
