# Workshop

## Desktop Pet for Windows

[![Download for Windows](https://img.shields.io/badge/Download-Windows%20Installer-0078D4?style=for-the-badge&logo=windows)](https://github.com/YeweonJung/workshop/releases/latest/download/Install-DesktopPet.cmd)

**[Windows 버전 바로 다운로드](https://github.com/YeweonJung/workshop/releases/latest/download/Install-DesktopPet.cmd)**

투명한 데스크톱 위를 돌아다니는 Windows 반려동물 앱입니다. 다운로드한 `Install-DesktopPet.cmd`를 더블 클릭하면 설치 위치, 시작 펫, Windows 자동 시작, 바탕화면 바로가기와 설치 후 실행 여부를 선택할 수 있습니다.

### 주요 기능

- Dog, Cat, Rabbit과 사용자 이미지 커스텀 펫
- PNG/JPG 얼굴 후보 감지와 수동 crop
- Floating Face, Mini Human, Cat/Dog Body, Chibi
- 랜덤 행동, 마우스 따라가기, 드래그, 위치 잠금
- 투명 영역 클릭 통과와 멀티 모니터 지원
- 모든 사용자 이미지 처리와 저장은 로컬에서만 수행

### 다운로드 파일

- `Install-DesktopPet.cmd`: Windows 단일 파일 설치기
- `DesktopPet-Source-v1.0.0.zip`: 전체 PowerShell/WinForms 소스

자세한 사용법과 새 펫 추가 방법은 Release의 소스 ZIP 안 `README.md`에서 확인할 수 있습니다.
