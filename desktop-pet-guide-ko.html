3단계로 설치

관리자 권한 없이 기본 사용자 폴더에 설치됩니다.

1

다운로드

Install-DesktopPet.cmd를 내려받습니다.

2

더블 클릭

파일을 실행하고 설치 위치와 원하는 옵션을 선택합니다.

3

펫 만나기

설치가 끝나면 화면 오른쪽 아래에 펫과 트레이 아이콘이 나타납니다.

Windows 보안 안내
현재 설치기는 디지털 서명되지 않은 CMD 파일입니다. 브라우저 또는 Windows가 경고를 표시할 수 있습니다. 이 GitHub 저장소에서 받은 파일인지 확인하고, 신뢰하는 경우에만 실행하세요.

자주 묻는 질문

종료하려면 어떻게 하나요?

펫 또는 시스템 트레이의 발바닥 아이콘을 우클릭하고 Exit를 누르세요.

삭제하려면 어떻게 하나요?

Settings에서 Start with Windows를 끄고 앱을 종료한 뒤 설치 폴더와 바탕화면 바로가기를 삭제하세요. 커스텀 펫을 보관하려면 먼저 user_pets 폴더를 백업하세요.

얼굴 감지가 안 되면요?

오류가 아닙니다. 사진 위를 드래그해 사람, 동물, 캐릭터, 인형, 밈 등 원하는 영역을 직접 선택할 수 있습니다.
